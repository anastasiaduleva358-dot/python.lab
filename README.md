# Скриншоты работы приложения (смотреть в отчете .docx)

1. Главная страница (/) 

 

Главная страница веб-приложения. Отображает краткое описание проекта и навигацию по основным разделам системы. 

 

2. Список фильмов (/items) 

 

Страница списка фильмов. Реализовано отображение всех записей из базы данных в виде карточек с изображениями, рейтингом и жанром. Присутствует сортировка и удаление записей. 

 

3. Добавление фильма (/add) 

 

Форма добавления нового фильма. Реализована проверка введённых данных и валидация пользовательского ввода. 

 

4. Страница одного фильма (/items/id) 

 

Страница одного фильма отображает подробную информацию о выбранной записи. Данные загружаются из базы данных SQLite по уникальному идентификатору (ID), который передаётся через URL-адрес. 

 

5. Статистика (/stats) 

 

Страница аналитики данных. Отображает агрегированные показатели: количество фильмов, средний рейтинг и распределение по жанрам. 

 

6. Ошибка (error.html) 

 

Страница обработки ошибок. Отображается при попытке доступа к несуществующему объекту. 

 

7. Фильтрация и сортировка 

 

Демонстрация работы сортировки и фильтрации данных. Пользователь может изменять порядок отображения записей.

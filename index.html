Каталог фильмов

Это веб-приложение для управления коллекцией фильмов. Пользователь может добавлять новые фильмы, просматривать список, открывать подробную информацию и анализировать данные.

Навигация по приложению

  • Список фильмов - просмотр всех записей
  • Добавить фильм - добавление нового фильма
  • Статистика - аналитика и данные

Возможности системы

  • Добавление фильмов в базу данных
  • Просмотр подробной информации о каждом фильме
  • Удаление и редактирование записей
  • Сортировка и фильтрация данных
  • Аналитика (средний рейтинг, количество по жанрам)
